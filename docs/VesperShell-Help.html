Getting started

  1. Install VesperShell or extract the complete portable folder.
  2. Launch the executable. Keep its _internal folder beside it if using the portable build.
  3. Type in any note; changes save locally after you pause typing.
  4. Find Vesper's icon in the Windows notification area near the clock (possibly behind ^).

Right-click the tray turtle for new notes, themes, restoring hidden notes, startup settings, and Help.

Note controls

ControlAction
+Create another note.
⌃Pin or unpin this note above other windows.
◉Choose a theme for this note.
◷Set a quiet deadline countdown.
⋯More actions, including scheduling, Help, save, delete, hide and quit.
×Hide a note. Does not delete it.
↓ Send backMove a note behind other windows without deleting or hiding it.
Ctrl+N / Ctrl+SNew note / save immediately.

Drag the header to move a note; drag its bottom-right grip to resize. Open the tray menu to restore hidden notes or bring a note forward.

Hide, Send back and Delete are different. Hide keeps saved text but makes the note invisible. Send back changes its window layer. Delete permanently removes the selected note after confirmation.

TurtleTick · quiet countdown

  1. Click ◷.
  2. Set hours and minutes, then start the countdown.
  3. Watch the green-to-amber-to-red progress indicator.

No sounds or flashing alarms. Deadlines remain correct across restarts. Use ⋯ → Clear countdown to remove one.

TurtleHide · scheduled visibility

  1. Open ⋯ → Schedule hide / reappear….
  2. Choose a one-time interval or a daily recurring hide/show window.
  3. Save the schedule. Daily windows can cross midnight.
  4. Use ⋯ → Remove visibility schedule to cancel it.

VesperShell must be running to respond to a scheduled change. If you're actively typing, it waits briefly before hiding. A manually changed visibility state holds until the next scheduled transition.

Start with Windows (optional)

Right-click Vesper's tray icon and check Start VesperShell with Windows. This is off by default and applies only to your Windows user account. Uncheck it to disable it. Keep the installed application folder in place while startup is enabled. QA mode intentionally disables startup changes.

To inspect your Startup folder: Win+R, then shell:startup.

Your notes, privacy and backups

VesperShell is local-first: no account, telemetry, cloud sync, or network connection required. Its data usually lives at %LOCALAPPDATA%\TurtleWorks\VesperShell\notes.json.

Notes are not encrypted. Don't store passwords or secrets. Anyone who can access your Windows files may be able to read your notes.

For a backup, quit VesperShell first. Copy notes.json, settings.json and the note-backups folder if they exist. Keep copies separately and never edit the working JSON blindly. Legacy TurtleNotes migration is designed to preserve old files.

Troubleshooting

My note disappeared.

Check the tray icon and choose Show all notes. The note may be hidden, behind another window, or waiting for a TurtleHide schedule.

I can't see the tray icon.

Look behind the taskbar's hidden-icon ^. If VesperShell isn't running, launch the executable again.

Help will not open.

Look for docs\VesperShell-Help.html beside the installed executable. Open the file in File Explorer. Restore the docs folder if it's missing.

Start with Windows doesn't work.

Confirm the executable hasn't been moved. Disable and re-enable the startup option from the correct installation.

Can I use Markdown, voice or syncing?

Not in this beta. Notes are plain text. Optional voice features, syncing and encrypted notes are possible future developments, not current capabilities.
